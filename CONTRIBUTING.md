# Contributing to IngesCompanyCC-LandingPage

First off, thanks for taking the time to contribute!

## Development Process
1. Use the develop branch as the base for your feature branches.
2. Verify your HTML and CSS with standard linters before committing.

## Commit Guidelines
We follow the [Conventional Commits](https://www.conventionalcommits.org/) specification. 
Please ensure your commit messages follow this format:
- eat(ui): add hero section
- ix(i18n): update spanish translations
- docs(readme): update structure

Do not use fast-forward merges when merging to develop.
