# Changelog

## [1.0.0] - 2026-10-09
### Added
- Hero section and navigation with anchor links to every section.
- Workspace section with segment access to the Web Application (`/sign-in/qa`, `/sign-in/production`, `/register`).
- Services, Features (accordion and preview panel), About the Product (video player), Benefits, Plans (monthly/annual toggle), About Us, Team, Testimonials, FAQ and Contact (inquiry form with validation) sections.
- Footer with link groups, language switch and segment access.
- Terms of Service and Privacy Policy pages.
- Full-screen mobile menu and responsive breakpoints for tablet and mobile.
- Skip link, SEO meta tags, favicon and custom cursors.
- Bilingual setup (English and Spanish) via JS modules.
